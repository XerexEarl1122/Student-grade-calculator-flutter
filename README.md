# 🎓 Student Grade Calculator

A simple and professional Student Grade Calculator application built using **Flutter and Dart**.

## 📱 About the Application

The Student Grade Calculator helps students calculate their average grade from three subjects and determine their academic result.

## ✨ Features

- 👤 Enter student name
- 📚 Enter grades for three subjects
- 🧮 Automatically calculate the average
- ✅ Display Passed or Failed result
- ⭐ Display performance remarks
- 🔄 Clear all input fields
- 📱 Clean and user-friendly interface

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design

## 📊 Grading System

| Average Grade | Result | Remarks |
|---|---|---|
| 90 - 100 | PASSED | Excellent |
| 85 - 89 | PASSED | Very Good |
| 75 - 84 | PASSED | Good |
| Below 75 | FAILED | Needs Improvement |

## 🎯 Purpose

This project was created as a simple Flutter and Dart application to demonstrate basic mobile application development concepts.
